Reading an intrusion, step by step

Illustrative phishing-to-ransomware walkthrough. Select a step.

  1. Look for: an Office process starting a shell, such as WINWORD.EXE spawning cmd.exe or powershell.exe (Sysmon Event ID 1), plus the matching email gateway record.
  2. Look for: long Base64 command lines and hidden windows. Script block logging (Event ID 4104) shows the decoded content.
  3. Look for: new values under the registry Run keys (Sysmon Event ID 13) pointing to a file in a user-writable folder.
  4. Look for: an unexpected process opening lsass.exe with read access (Sysmon Event ID 10).
  5. Look for: a network logon (Event ID 4624, type 3) from a workstation that never connects to that server, followed by admin share access (Event ID 5140).
  6. Look for: a burst of file renames and writes, and shadow copy deletion. Response: isolate the host, preserve evidence, then scope the spread.
